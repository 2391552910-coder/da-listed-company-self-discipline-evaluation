## 核查结论

阶段2至阶段7的文档、双源检索、持久任务、固定/Agent评价、证据定位、冻结报告、实验和部署代码已实现。逐项核对阶段1页面与接口设计后，仍发现下列查询和浏览功能遗漏。本轮先补齐系统功能；不将已通过的流程测试解释为完整研究验收，也不启动前端风格重构或安装设计skill。

| 设计项 | 原行为 | 本轮实现 |

| 公司管理 | 一次读全库，在浏览器筛选，无分页 | 服务端字面搜索、稳定分页；共享远程公司选择器，精确回填不在首页的公司 |

| 解析片段 | 只展示首20条 | 固定版本和解析批次的片段分页、原文位置核查及读取失败重试 |
| 评价运行历史 | 前端只有翻页，后端不支持方法过滤 | 公司/年度/固定或Agent/状态组合过滤，过滤先于分页；旧无mode记录归为固定双源 |

## 统计口径

- 年报按明确公司与报告年度限定。法规是独立共享资料库，不能用公司或报告年度筛选冒称其法律适用性。
- 总览覆盖读取已校验的冻结回答上下文。来源进入上下文、机械引用校验、回答标记资料不足分别计数；这些数据不是质量评分或语义支持认证。
- 覆盖最多检查最近500次运行，响应记录遗漏数量和截断状态；重复运行、实验对照及重试按运行次数计数。其他总数与状态计数不受该覆盖窗口上限影响。
- 损坏、缺失或没有可靠终态提交证明的快照计入未知，并给出问题运行标识；不将未知当成有效零分。
- 统计和查询不会调用生成模型。公司搜索中的 `%`、`_` 等作为字面字符处理。

## 明确边界

- 第三章AHP-Transformer数据与结果导入按已确认范围继续等待用户提供；系统保持空值，不训练替代方法，不显示虚构指数。
- 原文核查目前为只读；所有人工证据支持状态保持未复核。实验中的独立人工质量评分不等于对每条论断作出人工支持确认。
- 重试沿用阶段3/4约定：失败、取消或预算耗尽的任务创建新身份并重跑冻结请求，旧运行不覆盖；不提供部分成功运行的逐题重试。
- 真实生成服务实跑、真实研究材料的固定/Agent效果比较，以及目标Windows/GPU与正式服务器最终验收仍待执行。合成资料的自动化测试不替代这些验收。
- 本轮未安装或使用第三方前端设计skill。先完成功能核查，再安排视觉设计与动效工作；苹果发布会风格需求已保留。
